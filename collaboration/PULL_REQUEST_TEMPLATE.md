# PR 正文模板

## 目的

- 关联 Issue：
- 负责人及写入目录：
- 基线 `main` SHA：
- 分支及最新提交：

## 输入与输出

| 输入版本与来源 | 命令或人工核查步骤 | 输出路径 | SHA256 | 证据链接 |
|---|---|---|---|---|
| | | | | |

环境、参数与随机种子（适用时）：  
文献或资料来源及检索日期（适用时）：

## 结果与限制

- 已完成且可核查：
- 未完成、失败或无法复现的项目及原因：
- 证据类型：计算研究／文献资料／湿实验待验证／其他（说明）：
- 赛事官网提交回执状态（涉及提交时）：

## 提交前检查

- [ ] 改动在认领目录内；跨目录改动已获负责人确认。
- [ ] 每批成果完成后 5 分钟内 push，Issue 有对应提交链接。
- [ ] 关键数字、图表和结论有来源及限制说明。
- [ ] 文件路径使用仓库相对路径；无凭据、个人资料或本机绝对路径。
- [ ] 未将计算预测写成湿实验、疗效或赛事已提交。
- [ ] 非作者审阅人和审阅链接已填写。
- [ ] 审阅意见已处理，未完成项已登记。

合并后由 A 记录：merge commit、状态表更新、发布决定或阻塞原因。

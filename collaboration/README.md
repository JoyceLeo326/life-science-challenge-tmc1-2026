# 三人协作入口

本目录用于 TMC1 项目的公开协作。A 负责总控与发布，B 负责科学材料，C 负责计算复现。协作者在各自 Issue 中认领；用户名、Issue 编号、分支和 PR 链接以实际创建结果为准。

今天按 [协作流程](TEAM_COLLABORATION.md) 工作，在 [当前状态](CURRENT_STATUS.md) 登记证据。建任务时复制 [A 总控 Issue](issues/ISSUE_A.md)、[B 科学材料 Issue](issues/ISSUE_B.md)、[C 计算复现 Issue](issues/ISSUE_C.md)；提 PR 时使用 [PR 正文模板](PULL_REQUEST_TEMPLATE.md)。

公开材料只记录可核查成果。现有筛选与候选排序属于计算研究，湿实验验证仍待完成；赛事正式提交须以官方回执为准。

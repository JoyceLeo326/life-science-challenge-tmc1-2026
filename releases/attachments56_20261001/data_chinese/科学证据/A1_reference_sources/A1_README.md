# 参照库来源核查

本轮未找到可逐条复核的“68个独立阻断剂”完整成分来源，因此不生成虚构的68行成分表，也不报告“与68库零重叠”。作者冻结提交 74274dad76201258adbd76c7058b705170c4b857 的10份模型活性SDF包含78个重复记录、12个独立训练结构；论文补充表列13个训练名称，另有3个对接参照。这个训练集合与论文12个染料摄取活性候选是两个集合，不能按数量相同互相替代。

本轮真实比较：将6个正式候选和上述12个训练结构用 RDKit FragmentParent + Uncharger 后的完整 InChIKey 比较，交集为0。零重叠只说明此有限、已核对集合中没有相同标准化母体；既不证明新化学型，也不能排除参照覆盖、制备规则或打分方法的局限。更不能外推成对未核实68库的全面查新。

论文的12个活性候选是小鼠耳蜗外植体染料摄取读出，不能写成人源TMC1直接结合或选择性证据。数据库结构恢复补回3个准确ZINC条目，另外2个仍缺可确认结构；明细保留每条来源和限制。

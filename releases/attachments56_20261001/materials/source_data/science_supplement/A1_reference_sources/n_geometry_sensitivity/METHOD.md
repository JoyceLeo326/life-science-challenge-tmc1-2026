# 三个参考分子的氮几何敏感性分析

## 为什么补做

从官方 ZINC 接口补回的三个分子均不缺少来源碳手性或 E/Z 信息。旧制备流程在 pH 7.4 质子化后将一个原本中性的非环状叔胺 N 识别成未指定四面体中心，因旧例外仅覆盖单环 N 而停止。这是现有表述规则的边界，不能直接推断分子不适于计算。

RDKit 的潜在立体中心识别将三重原子连接加一个隐式 H 的中心纳入候选；其枚举工具允许只枚举未指定的中心，并保留已有立体信息。[RDKit Book](https://www.rdkit.org/docs/RDKit_Book.html) [枚举工具文档](https://www.rdkit.org/docs/source/rdkit.Chem.EnumerateStereoisomers.html)

已有化学原始研究说明，多数中性叔胺的氮构型在室温可快速翻转，而受限桥头结构及季铵体系可表现不同稳定性。这不能直接给出本次三个质子化分子在 pH 7.4 的交换速率。因此本分析采用两种固定 N 几何，不假定快速交换或任何比例。[Zaitseva et al., Organic Letters 2023](https://pmc.ncbi.nlm.nih.gov/articles/PMC10028698/)

## 预先限定的变化

仅枚举原来源 N 不带电、无指定构型且不在环中，经原 pH 规则形成 N+H 的位置。必须是一个非芳香、非羰基或硫羰基相邻的叔胺 N，且原子连接图和键级保持一致。每个分子只允许有一个这样的新增中心；出现未定义碳、双键、环内 N、酰胺 N 或来源本身的未知立体信息时仍停止。

每个母体枚举两种 N 几何，合计 3 个母体、6 个准备及对接任务。所有已指定的其他立体信息保持，枚举前后清除新增 N 标记后结构必须相同。既有 3 次原规则阻断完整保留；本次结果不计入原冻结筛选或参考物命中率。

## 其他参数保持

同一个 M_PUB_ALL 受体、冻结框、Vina 1.2.7、种子 20260927、exhaustiveness 8、每任务 2 CPU、每次 9 个姿势。每种 N 几何仍独立生成 10 个 ETKDGv3 构象并用 MMFF94s 优化。仅执行一条对接任务流以控制计算负载。

每个几何单独保存制备、原始分数、结构和 QC。必须报告两种几何的全部结果和分数区间，不能只选较好者充当已验证参考值。氮几何、pH 微状态、受体构象仍是模型假设，不能由本补算推导真实结合或通道激活作用。

## 排除 Ceforanide 的原因

Ceforanide 受影响的 N 同时在四元和六元环中且邻接羰基，不满足本分析的非环状非酰胺条件。7 项规则检查包括 6 个允许枚举的案例与 1 个必须拒绝的 ceforanide 案例，均按预期通过。其位点需要单独审查质子化化学，不能借本次限定扩展放行。

完整判据见 `SENSITIVITY_PREREGISTRATION.json`、`protocol_inputs/n_geometry_rule.py` 与 `rule_validation.json`。

# 对接姿势图说明

示例候选为 LIB_DNDVGFIEWOHGAH（DND）。图件直接读取已完成的四项正式确认作业首姿势和相应对齐受体坐标，仅改变观察相机、外侧空白裁切、等比缩放与图注，没有重新对接、重打分、改变结构或生成新的原子坐标。

单候选示例使用 M_PUB_ALL / seed 20260928。四条件图分别使用 M_PUB_ALL / seed 20260928、M_PUB_ALL / seed 20260929、M_PUB_CORE / seed 20260927、H_AF / seed 20260927，采用相同观察方向。彩色球棒展示实际候选原子；青色标出近邻中区残基，蓝色为局部蛋白骨架。小分子碳原子为橙色，氮为蓝色、氧为红色、氟为淡绿色。

单候选图残基标签取 A 链15个预先定义的中区残基中，与候选所有重原子的最小欧氏距离最短的3个；四条件图每面板仅标出最近的1个中区残基。显示口袋为含任一重原子距候选重原子不超过4.5 Å的完整残基；局部骨架显示距候选9 Å以内的A链完整残基。标注是静态几何接触，不代表氢键、结合常数、活性或功能调节方向。图中未绘制或断言任何氢键。此四面板为一候选的4项计算示例，不代替六候选全部24项的汇总。

PNG为真实坐标的PyMOL光线追踪渲染及中文注释；PDF为该图的高分辨率栅格版本；SVG嵌入同一栅格图，未声称为原子图的矢量表示。匿名来源文件标识与SHA256见 pose_visualization_source.csv，详细坐标一致性核验见内部绘图回执。

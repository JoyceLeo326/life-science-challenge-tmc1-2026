# 三物种材料更正短稿

旧版“四个Middle同源位点在虫结构中缺坐标”应更正为“原全长映射在TM5–TM6长环插入附近错位”。经人/鼠两路结构叠合及独立TM分段序列审查，人531/534/535/539对应虫683/686/687/691；四位点在7USW/X/Y均有完整实验重原子。真正未解析环为460–663，原760行表保留作历史记录，局部修正不代表整表已验证。

补充筛选采用运行前冻结的新7USX原生坐标蛋白条件：15位点完整，已观测盒+8Å邻域重原子覆盖完整；原7USW图和238核心指标与新7USX指标分开标注。6候选+2数据库来源参照×3静态结构24格均有真实分数，蛋白条件QC23/24；虫indinavir因首构象超冻结盒边界保留失败。另两虫参照使新虫10实际作业、蛋白QC9/10；amiloride原化学门禁阻断，未改互变异构表示。

全部10虫首构象均与省略的实验非蛋白模型原子重叠（D12/R16实验结构烃片段及3PE磷脂等），只能解释为蛋白only探索。烃片段逐项来源未确认，不能统称生理脂质；蛋白几何通过不等于膜环境相容，重叠也不直接证明实验不能结合或排除置换。虫构象contracted未证明closed，跨物种分数不等同亲和力/药效；参照不称直接TMC1阳性；R2主排名、阈值及已交付包均保持原记录。

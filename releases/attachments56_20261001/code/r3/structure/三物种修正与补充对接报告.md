# 三物种局部映射修正与7USX补充对接

## 已完成的结果

原“四个Middle位点缺坐标”来自同源映射错位。人531/534/535/539应对应虫683/686/687/691，分别为TM6的D/F/T/I；人454对应虫440，原局部离群人543对应虫695。真实未解析区域是虫TM5–TM6环460–663（204残基），不应将该环的缺失投射到真正的TM6位点。人/鼠两路非强制结构叠合与独立TM分段序列审查支持这些局部修正。原760行表保留；其中还有其他错配，不能将替换几个点称为整表修正。

新15位点在7USW、7USX、7USY均有实验CA及完整标准重原子（126个）。由于7USW/Y的固定盒邻近存在未解析侧链，本次在分数出现前选择7USX的已观测局部蛋白重原子完整区域。该条件使用实验原生坐标，无补造重原子：搜索盒中心(136.5105,174.4235,172.8190)Å，边长(33.721,32.575,26.328)Å，由15位点重原子范围每面加5Å定义。受体准备省略48个远端不完整残基，其已观测原子距离盒至少13.1635Å；位点126重原子坐标完全保留。远端CALM链C/E I201仅终端O/OXT名称互换，坐标集合不变。未解析柔性环可能访问口袋仍未验证。

## 真实计算与审计

六候选×三静态结构的18格已齐；加indinavir anhydrous数据库母体与posaconazole数据库母体构成24个有真实分数的格子，其中12格复用原R2候选、2格复用R3鼠参照、10格来自本次新作业（6虫候选+2虫参照+2人参照）。另有lapatinib、denatonium两个虫参照作业，合计本次12个新完成作业。虫输入11条中amiloride按原潜在双键立体门禁阻断，不改互变异构表示绕过。

蛋白条件QC：24格矩阵23/24通过；虫10实际作业9/10通过，六候选6/6通过，六候选Middle4Å接触2/6。虫indinavir首构象分数−7.996，但盒边距−0.148Å低于冻结−0.1Å，保留失败及原分数，不扩大盒、不挑后续构象。新增人参照2/2通过：indinavir−10.192，posaconazole−10.495，两者Middle接触通过。候选六份配体与原R2的SDF/PDBQT/规则身份完全一致；参照与原鼠对应文件一致。

**全部10个虫首构象与本次省略的实验HET坐标发生<1.5Å重叠，包括六候选全部。** 主要重叠CCD为R16（hexadecane）、D12（dodecane）及3PE（实验结构中建模的磷脂）。各成分化学名/结构来源性质见独立审计表，烃片段、磷脂、去污剂不能统称生理脂质。蛋白几何通过不等于膜环境相容；空间重叠也不能直接等同实验不能结合，置换可能性尚未实证。结果只支持蛋白条件下的探索，后续需要保留结构环境的竞争占位或整膜建模再评价。本次不新增MD或NMA。

新broad-TM observed-CA叠合：H/M 553对，RMSD2.94Å、TM0.91131/0.91131；H/X 482对，RMSD3.50Å、TM0.75745/0.81946；M/X 504对，RMSD3.58Å、TM0.77803/0.84056。TM值分别按输入长度H566/M566/X520归一，含已建模跨膜间环，非全长指标；不与旧7USW的238同残基核心指标混写。

## 使用范围与复现

7USX的contracted是实验几何分类，未证明为closed功能态。人/鼠与虫受体来源、组成、构象、搜索盒不同；分数仅按各条件描述，不能直接解释跨物种亲和力、抑制效力或人体药效。未加鼠评分门限，未更新R2主排名。参照的2025耳蜗染料摄取证据不等于直接TMC1结合/功能阳性；denatonium为比较物，amiloride为原门禁阻断记录。

原模型不分发；包内仅含官方实验7USX派生静态PDBQT及配体结果。复现所需人/鼠受体由获授权者外部提供，并核验冻结SHA。完整实际原始配体、全部Vina模式、日志、24格表、失败记录、双冻结条件、旧新映射、独立审计、图和匿名复现脚本均在包内。脚本与文件级复现核查见README与public_readback_qc.json。

## 非蛋白结构环境补充说明

论文Methods为GDN提取/纯化环境（提取2%，SEC纯化0.02%，含CaCl2）。CCD证实D12为dodecane、R16为hexadecane；不能由化学名或该纯化背景推断每一烃片段的实际来源、是否对应特定去污剂片段或生理脂链。3PE/PEE为磷脂酰乙醇胺类别。官方7USX LINK还显示TMIE的PLM脂酰共价连接与TMC1 NAG糖基连接，本蛋白only条件省略了这些非蛋白修饰环境。详见独立HET来源审计；重叠只描述与冻结模型配置不相容，不证明实验无法结合。

匿名包实读26个冻结作业，与原独立QC裁决26/26一致（蛋白条件25通过、虫indinavir1失败）；受体从官方PDB重新准备得到相同SHA。公开脚本实际复跑第一个虫候选，分数与首pose SHA均精确一致。

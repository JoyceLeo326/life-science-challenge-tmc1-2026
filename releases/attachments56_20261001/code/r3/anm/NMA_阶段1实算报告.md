# TMC1单链Cα正常模分析：第三轮阶段1实算报告

## 1. 目的与实际范围

按阶段1手册的无GPU正常模分支，在既有固定结构上执行可核查的低成本弹性网络分析。主分析为人源H_AF链A183–734（552个Cα）及小鼠M_PUB_ALL链A177–731（555个Cα），包含该跨膜包络内的连接环与实际插入位置。其边界来自人UniProt首个至末个跨膜注释及既有鼠对应，不是只截取15个口袋残基或238点叠合核心。

另计算完整实有单链对照：人A1–760共760个Cα；鼠A81–746共666个Cα。鼠源文件虽含六蛋白复合物，本分析仅使用TMC1链A，未包含其它亚基、二聚体接触、脂质、膜或溶剂约束。线虫局部映射由另一独立任务核查，本附件没有填补缺失残基或解除其对接阻断。

输入源SHA与所用区域见`PROTOCOL_FROZEN.json`、`SOURCE_INDEX.csv`及`CA_node_index.csv`。原坐标保留，未改R2红线区任何文件。

## 2. 冻结方法

方法在2026-09-30北京时间21:54:29冻结，实际计算21:54:40–47完成，耗时7.08秒。

采用标准Cα各向异性网络模型ANM：节点间距离≤15 Å时建立统一弹簧，γ=1为相对单位；13 Å为事先声明的截断敏感性。完整单链对照只用15 Å。按标准块公式构建3N×3N Hessian，用SciPy对称特征分解。完整谱保留用于正半定和零模检查，实际分析保留前20个非零模。零值阈值事先固定为绝对1×10⁻⁶，未依据候选分数调整。

环境为Windows、Python3.12.10、NumPy2.5.3、SciPy1.18.1。实际OpenBLAS线程均为2。主域单个Hessian约21 MiB，最大完整单链Hessian39.66 MiB；这仅是矩阵存储，未把它称作进程峰值内存。

本次运行透明SciPy实现，并在六个网络上逐值核对固定ProDy v2.6.1官方`buildHessian`的已审阅、哈希验证分支。本环境未安装完整ProDy，参考函数由限定的ndarray/统一γ/稠密分支包装调用，不声称运行其解析器、其它扩展或整套软件。理论和参数见[原始ANM论文](https://doi.org/10.1016/S0006-3495(01)76033-X)及[ProDy官方ANM API](https://www.bahargroup.org/prody/manual/reference/dynamics/anm.html)。

相对MSF计算为前20模的Σk‖uik‖²/λk，再在同一节点集合上除以均值。它是有限低模的相对协方差对角项，不是总热涨落，不是温度标定的Å²，也不是MD RMSF。图F2的完整链曲线先限制到共同跨膜域，再在该共同域上归一化。

## 3. 数值与来源质检

六网络全部只有1个连通分量、恰6个刚体零模、无低于−1×10⁻⁶的特征值。最小节点度数5–12，无孤立节点。源码交叉核验的Hessian最大绝对差为1.07×10⁻¹⁴；矩阵归一的特征对残差≤5.91×10⁻¹⁷，正交误差≤2.67×10⁻¹⁵，刚体基残差也通过。

独立检查另外用全距离矩阵和不同块累加公式重建六个网络，复核保存模态与MSF；用不同`evr`求解器重算人域15 Å低26谱，最大特征值差8.06×10⁻¹⁵。按每个特征值尺度计算的独立残差最大3.43×10⁻⁹，主要来自人完整链软模。节点身份、插入码歧义、24帧位移与13项几何指标全部实际复核通过。

人完整链最低正特征值6.16×10⁻⁶，仅为冻结零值阈值的6.16倍；完整链包含很软的末端/环区模。`ZERO_THRESHOLD_DIAGNOSTIC.json`列事后阈值诊断，未改变冻结模态选择。所有质量数值见`network_numerical_QC.csv`和独立QA表。

## 4. 截断距离和切取边界

| 比较 | 人源 | 小鼠 |
|---|---:|---:|
| 跨膜域15/13 Å低20子空间RMSIP | 0.9529 | 0.9684 |
| 跨膜域15/13 Å相对MSF Spearman | 0.9870 | 0.9898 |

| 跨膜域与完整链限制区域MSF Spearman | 0.6367 | 0.7256 |

RMSIP是子空间重叠，不是构象RMSD或结构TM-score。截断距离下总体低模子空间较接近，但最大主角度仍达约61–69°，不能说每个模逐一相同。切取边界影响明显，不能把跨膜域模态代替完整膜复合物动力学。完整链限制后的20列实际秩均20，子空间投影没有用任意补全方向凑指标。

## 5. 构象与几何诊断

预先固定前两个非零模、两个方向，整组Cα位移RMS尺度0.25/0.5/1 Å，共24帧。公式为x=x₀±a√N·u，向量u单位归一；符号仅为可重复的数学约定。0.5 Å作为展示档，另外两档为数值尺度诊断。参考静态Cα与全部帧均内部保存。没有随机采样、候选分数驱动选帧或为了改善命中而改变尺度。确定性模态遍历的尺度约定可参照[ProDy官方构象生成说明](https://www.bahargroup.org/prody/manual/reference/dynamics/sampling.html)。

粗粒参考诊断事先固定：相邻实有序列Cα距离改变≤0.20 Å、中区15个Cα最大两两距离改变≤1 Å、非相邻Cα小于3 Å的对数不增加、15节点保持在冻结盒内。它们是本项目的失真标记，不能当作文献验证的生物学或全原子受体门槛。

| 全局Cα RMS位移设定 | 人域诊断通过 | 鼠域诊断通过 | 全原子对接合格 |
|---|---:|---:|---:|
| 0.25 Å | 4/4 | 4/4 | 0 |
| 0.5 Å | 2/4 | 4/4 | 0 |

0.5 Å档人mode2双向均被相邻Cα距离变化标记；全部失败帧保留。该档局部最大位移2.60–4.52 Å，最大相邻Cα距离改变人0.2833 Å、鼠0.1788 Å；中区CA两两距离最大改变人0.0172 Å、鼠0.0095 Å。小的口袋Cα变化不等于重原子口袋已验证。

低模位移主要集中在人497/326、鼠494/715附近。独立参与率约0.024–0.079，中区15节点仅占模态平方位移的0.10%–0.32%。源模型置信度/结构缺失和低频环区局域性影响解释；原B列保留为源模型元数据，未当作实验B因子或预测RMSF。该结果不足以称为口袋主导运动或通道开闭。

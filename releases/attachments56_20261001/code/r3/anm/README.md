# TMC1 第三轮正常模分析附件

本附件完成了人、小鼠 TMC1 单链跨膜相关区域的真实 Cα 弹性网络分析。已生成低频模态、24个可核查的确定性位移构象、相对均方位移及四组科研图，并完成独立数值复核。

## 先看什么

- `NMA_阶段1实算报告.md`：方法、结果、实际限制与下一步。
- `figures/F2_relative_MSF_and_boundary.png`：截断距离与切取边界的影响。
- `figures/F3_traversal_geometry_diagnostics.png`：所有振幅、失败标记和局部最大位移。
- `independent_QA/ACTUAL_QA_REPORT.md`：独立检查，含6个网络和24帧逐项复核。
- `MANIFEST.json`、`SHA256SUMS.txt`：本匿名附件的文件校验。

## 这份结果支持什么

六个网络数值检查通过。15 Å和13 Å截断下，跨膜域的低频子空间较接近；改用完整单链后，低模与相对位移分布明显变化。低模运动主要集中在中区15个残基之外。

预定0.5 Å是**整组Cα位移的RMS尺度**，单个残基可移动2.60–4.52 Å。该档8帧里6帧通过粗粒几何诊断，2个人源帧保留失败标记。全部24帧均未经过全原子重建、松弛与受体质检，因此可用于模态分析，尚不能直接用于全原子对接。

这不是MD、热力学采样或开放/关闭通道的证据。辅助亚基、二聚体接触、脂质和膜约束未进入本弹性网络；线虫位点映射与三物种共识仍需独立完成。R2已交付的模型、盒、库及主结果未修改。

## 数据与文件边界

本包含匿名数值表、模态向量、位移向量、图件、代码、来源和实际测试回执。`*_modes.npz`包含特征值、特征向量和残基编号，不包含源坐标。

源受体及派生Cα坐标保持在内部研究目录。原作者小鼠模型未见独立再分发许可，本包不装入该模型或派生PDB。源输入须由复现者从固定来源自行取得并恢复，SHA256必须匹配。ProDy参考源码的上游许可单独保存在`reference_code/ProDy_v2.6.1_LICENSE`，该许可不扩展到受体模型。

## 运行

见`REPRODUCE.md`。实际实现是标准ANM的SciPy程序，并与固定、审阅过的ProDy v2.6.1 `buildHessian`源码逐值交叉核验；本环境未安装完整ProDy，不将结果写成完整ProDy工具包运行。

每个CSV、NPZ和图件都可用独立文件清单追溯。使用`python verify_manifest.py`检查附件。

# B 工作区：计算、代码和证据

领取 [Issue #2](https://github.com/JoyceLeo326/life-science-challenge-tmc1-2026/issues/2)，分支建议 `work/b-compute`。

## 本次必须交付

1. `compute_inventory.csv`：库、受体、任务、候选和图件的真实版本/计数/来源路径/SHA256。核对 9098 的具体统计口径与三物种结构，不把不同筛选阶段分母混用。
2. `reproduce.md`：新设备环境、所需软件及版本、输入、命令、参数和种子、输出位置。分别标清可直接重绘、可以补输入重跑、仍缺原方法的任务。
3. `environment/` 和 `src/`：可公开的依赖说明、入口及必要代码修正。已有冻结源码在 `science/`，在此工作区保存本轮修订。
4. `results/`：候选表、对照/确认计算汇总、逐图数据、图号索引与文件校验。保存真实失败和排除原因。
5. `reproduction_status.csv`：每个入口是否执行、真实命令与输出、失败原因和待补项。已有结果直接整理，不重复启动仍在运行或无必要的计算。

先读 [复现入口](../../science/REPRODUCIBILITY.md) 与 [科研索引](../../science/README.md)。B 负责数值和底层科研图，不改 A 的核心科学文字；C 负责最终视觉排版，使用 B 已确认的数据与图件。

向 A/C 交接候选编号、图号、单位、统计分母和结论适用范围。计算排序不等同于实验活性。每批结果完成后 5 分钟内推送，科学脚本运行完同时上传参数和日志。

# A 工作区：科学依据与项目逻辑

领取 [Issue #1](https://github.com/JoyceLeo326/life-science-challenge-tmc1-2026/issues/1)，分支建议 `work/a-science`。

## 本次必须交付

1. `requirements.csv`：比赛官方要求、来源链接、页码、对应材料、是否满足。以真实官方原文为准。
2. `claims_and_sources.csv`：每条关键结论、证据类型、原始出处、支持范围、在正文中的位置。处理 USH1B/MYO7A 与 TMC1 关系、流行病学分母、已有治疗进展及创新比较。
3. `scientific_text.md`：研究问题、机制依据、筛选思路、结果、讨论、局限和后续验证。R2 的已完成结果与 R3 的推断分开。
4. `abstract.md`：符合官方格式的摘要。具体字数由 `requirements.csv` 记录，避免凭印象编定。
5. `r2_r3_corrections.md`：需要修改的原句、修正后文字、依据以及影响的图表/页码。重点复核历史参考图中从序列同一性直接推导对人疗效的表述，以及阶段零流行病学分母；引用前先核对证据适用范围。

先读 [科研入口](../../science/README.md)。研究数据和数字向 B 索取，排版与 PPT 制作交给 C。A 负责解释和文字，不重新做计算或另起一套演示稿。

交接给 C 时写清正文版本、可使用结论和待核实项目；B 复核数字与候选口径。领取后 15 分钟内推送工作计划，每批完成后 5 分钟内推送实物。

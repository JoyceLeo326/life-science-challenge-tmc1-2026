# 阳性参照方法验证页

## 口径

本页把 `REF003` 作为文献参考分子和流程控制，核对输入身份、受体配置、Vina运行、姿势输出和几何质量。它的角色字段是 `heterogeneous_literature_reference_not_direct_human_binding_positive`，因此这里的“阳性参照”只表示方法学参照，不能把它写成已经在本项目中证明的人源TMC1阳性配体。

## 已核对项目

- 两个固定随机种子：20260927和20260929
- 四个受体输入：H_AF、M_AF、M_PUB_ALL、M_PUB_CORE
- 每个作业均记录输入哈希、受体哈希、盒参数哈希、Vina版本哈希和姿势文件哈希
- 作业返回码为0，姿势数和分数从原始作业账本读出
- 几何检查保留最小受体重原子距离、严重近接触数和盒边界余量

逐作业数值见同目录 `reference_method_validation.csv`。

## 结论边界

该页证明筛选方法具备可复核的控制入口，并展示了参考分子在不同受体状态下的计算读数。它不证明真实结合、功能激活、抑制或物种选择性；湿实验仍需按方案完成。

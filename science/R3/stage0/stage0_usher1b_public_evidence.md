# 第三轮阶段零 Usher 1B 公开资料核查

更新时间：2026-09-30（北京时间）

## 统一主线

阶段零统一采用「Usher 综合征 1B（USH1B，MYO7A）下游代偿策略」作为主线。R2 中的 DFNB 相关内容只作为原有计算证据保留，不作为新的疾病叙事。

## 可直接使用的事实

| 主题 | 可用表述 | 来源与边界 |
|---|---|---|
| 疾病定义 | USH1B 属于常染色体隐性 Usher 1 型，典型表现包括先天性重度至极重度感音神经性听力损失、前庭反射缺失和后续视网膜色素变性 | GeneReviews 和 Orphanet 均支持。临床表现存在个体差异，材料中不写成每位患者完全相同 |
| USH1 比例 | GeneReviews 汇总的全球基因组数据库估计 Usher 综合征总体患病率约 1/29,000，USH1 约 1/450,000；旧文献和 Orphanet 页面给出约 1/30,000 总体患病率、USH1 约 40% 的旧估计 | 新旧估计口径不同，正文优先使用 GeneReviews 的新估计，并在脚注注明估计依赖数据库与模型 |
| MYO7A 比例 | MYO7A 相关 USH1B 约占 USH1 的 60%–70%；GeneReviews 表中给出的 MYO7A 相关 USH1B 群体估计约 1/149,000 | 这是 USH1 内的基因归因比例，不等于所有 Usher 患者中 60%–70% |
| 病情负担 | 听力损失通常先天出现；前庭功能缺失可导致抬头、独坐和行走发育延迟；视网膜色素变性常从夜盲和周边视野缩窄开始并逐步影响视力 | Orphanet 对 USH1 的疾病定义；材料中写“通常/可出现”，不写绝对时间点 |
| 现有治疗 | 目前没有治愈 Usher 综合征的通用疗法；听力和交流支持包括助听器、人工耳蜗、听觉训练和手语；平衡与低视力管理包括定向行走和低视力服务 | NIDCD。高剂量维生素 A 不建议用于 USH1，因为关键试验未纳入 USH1 患者 |
| 临床转化现状 | LUCE-1（NCT06591793）是 AAVB-081 双 AAV8.MYO7A 的 1/2 期、开放标签、剂量递增研究，目标是评价安全性、耐受性和初步疗效；CTIS 记录为进行中且招募结束，计划 15 例 | HRA/CTIS 与研究方页面。不能写成已获批疗法或疗效已证实 |
| 技术理由 | MYO7A 基因较大，单个 AAV 载量受限，双 AAV 是当前临床转化路径之一；这支持“恢复下游功能”的研究逻辑 | AAVantgarde 与 Usher Syndrome Coalition 的项目说明；材料中标注为研究路径，不写成临床标准 |

## 三个必须补证的调查项

1. 流行病学：正文只使用 GeneReviews 新估计；如要写中国或云南地区数字，必须另找地区队列或系统综述，不能用全球估计替代。
2. 病情严重度：使用 USH1 的三联负担框架，不把所有患者写成同一年龄、同一视力进展速度。
3. 临床治疗现状：把人工耳蜗和低视力支持写成现行管理，把 LUCE-1 写成在研临床研究；不写“已经治愈”或“已获批”。
